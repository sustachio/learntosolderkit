# Electronics Club learn-to-solder kit

This was a learn to solder kit I developed for my school's electronics club consisting of an analog 3 note tunable keyboard with a 555 timer and piezo buzzer. More info can be found here: https://sethmueller.page/post/newspaper-article-hosting-a-learn-to-solder-day-at-lasa-electronics-club.
